# 技术来源

核对日期：2026-09-14。以下官方文档支持能力选择，不构成服务可用性或送达保证。实现时重新核对版本兼容与供应商条件。

- [Next.js 自托管](https://nextjs.org/docs/app/guides/self-hosting)：支持 Node.js 与 Docker 部署。
- [Docker 的 Next.js 容器化指南](https://docs.docker.com/guides/nextjs/)
- [PostgreSQL SELECT](https://www.postgresql.org/docs/17/sql-select.html)：行锁与 SKIP LOCKED，为队列认领提供基础。
- [Prisma 事务](https://docs.prisma.io/docs/orm/v7/prisma-client/queries/transactions)：关联写入的事务边界；此链接为版本化资料，实现时匹配所选版本。
- [Better Auth 配置](https://better-auth.com/docs/reference/options)：邮箱密码与关闭注册配置。
- [FullCalendar 许可](https://fullcalendar.io/license)：区分 Standard 和 Premium。
- [Nodemailer SMTP](https://nodemailer.com/smtp)：SMTP 发送配置。
- [Server酱文档](https://sct.ftqq.com/docs/)：后续微信推送备选。
- [PushPlus 使用限制](https://dev.pushplus.plus/doc/guide/use.html)：微信渠道实名与额度约束，实际接入时重新核实。

- [Mammoth 官方说明](https://github.com/mwilliamson/mammoth.js)：DOCX extractRawText 与安全注意事项，仅使用文字提取。
- [PostgreSQL pg_trgm](https://www.postgresql.org/docs/current/pgtrgm.html)：字符相似度与索引能力，不等同于中文语义检索。

- [Brave Search Web API](https://api-dashboard.search.brave.com/app/documentation/web-search)：联网调研接入的搜索端点和鉴权；当前未配置真实凭据进行联调。
