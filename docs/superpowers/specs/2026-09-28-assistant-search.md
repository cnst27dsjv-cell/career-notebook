# 助手联网搜索

沿用用户已选定的 Tavily + 现有文本模型方案。服务端读取 TAVILY_API_KEY，前端默认关闭联网；开启时仅将当前问题发送给 Tavily，不发送工作台资料与历史聊天。当前问题上限1000字，每次发送一次 basic 搜索，最多5个结果，不自动升级搜索深度。

搜索摘要与时间交给文本模型，回答以序号引用，持久保存来源标题、URL、摘要、检索时间。界面明确为搜索摘要，不代表全文或已确认报名状态。来源仅允许 HTTP(S)。联网失败显示错误，可手动重试，不能伪装搜索成功。

消息保存联网模式，重放检查模式一致；沿用每天30次助理调用限制。搜索超时15秒，模型60秒，消息等待期限120秒。正式记录仍须确认；网页内容不能赋予操作权限。

验证：Tavily 请求与来源过滤单元测试、现有测试、类型检查、一次真实搜索的浏览器测试，覆盖来源刷新恢复、消息重放、移动端。仅应用本地迁移，线上需另行配置密钥及迁移后部署。
