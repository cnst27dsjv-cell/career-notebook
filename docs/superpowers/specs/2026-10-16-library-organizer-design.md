# 原始资料与结构化练习库

用户已认可第一版：原始文档单独入口、逐篇 AI 拆分预览、人工确认入库、同题多版回答。沿用当前工作区与本地预览，不提交或发布旧的未提交工作。

- 原文保留，Obsidian 旧导入自动在原始文档入口展示；其他旧资料保留并可转为原始文档。Word/文字新导入先保存完整原文。
- 整理工作台左侧原文，右侧问答/经历/知识候选；回答、上下文、其他智能体建议分字段。保留精确原文引用，缺失回答允许空白，不能推断成事实。
- 用户可编辑、增加、删除候选（支持手动拆分/合并内容）、勾选部分入库、明确标记整理完成；保存草稿后可继续。原文更新时清除旧草稿与完成标记，已入库内容保持原样。
- 确认操作原子化、账号隔离、版本冲突检查；不能重复入库。相同问题可选择已有问题追加一个回答版本，不自动覆盖。来源记录文档ID、版本与原文片段。
- 资料库分问答、经历、知识、旧资料；保留岗位分类。已确认条目可回看来源和多版回答；模拟面试确认答案追加版本。助理检索优先相关的已整理条目，原始资料作为补充并标明类型。
- 不自动同步整个 vault，不写回个人文件，不进行跨文档自动合并。长文可分段选择后整理，不静默截断。
