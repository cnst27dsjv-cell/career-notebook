# 助理第一批交付与验收

日期：2026-09-27。状态：本地实现与验收完成；未执行生产迁移、发布或推送。

## 实际交付

- 按用户参考图实现酒红信封、奶油信纸、蜡封、左右对话、快捷问题和输入框；保留现有其他栏目。375px 手机适配。
- 持久化对话、消息、行动草稿及真实执行回执，刷新/跨设备恢复；最近 30 个对话可选择，每轮模型使用最近 12 条消息节选与当前草稿。
- 真实模型查询和连续指代；支持投递新建/修改、日程新建/改期/完成/取消、关联面试准备及已确认材料独立复用。每组最多 5 个正式操作。
- 一张可审阅卡展示前后差异、关联记录、提醒影响、缺失信息、冲突和来源。修改通过继续聊天重新生成整组草稿；用户点击确认才执行。旧的助理日程表单断链已由完整确认执行流程替代。
- 提取日程/投递共用业务写入函数，旧界面与助理使用同一逻辑。确认在一个数据库事务内完成，重复确认返回同一回执；外部模型不在事务内调用。
- 对象版本和日历快照校验、过期/放弃草稿拒绝、冲突明确确认、网络重试、失败消息恢复。准备记录增加版本；事件增加轮次。
- 招聘截图/链接复用原有导入组件：先提取到输入框，核对再发送；原图不在此入口保存为投递附件。
- 修复旧资料复用先截最近 100 条再检索的范围问题，先在账号全量资料中按条件过滤再限量。
- 聊天每日最多 30 次模型请求，单次最多 4000 输出 tokens；模型业务上下文约 24000 字符预算，标记截断；简历只发送元数据，尚未实现正文理解。
- JSON/ZIP 导出增加会话、消息和助理草稿。所有新 API 按登录账号隔离。
