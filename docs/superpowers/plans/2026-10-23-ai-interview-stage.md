# AI面阶段实现计划

**Goal:** 按用户要求，在笔试之后增加 AI面，支持时间安排和进度条。
**Architecture:** 沿用现有阶段/日程映射和完成状态逻辑；AI面是独立阶段和日程类型。阶段字段为字符串，无需数据库迁移。
**Tech Stack:** React、TypeScript、Zod、Prisma、Vitest。
**Spec:** 用户明确要求“笔试之后加AI面，也能安排时间、显示在进度条里”。已完成后等待下一阶段；不自动跳到面试。

- [x] 增加回归测试：AI面保存安排、手动完成、日程映射、进度顺序；原有面试不虚构AI面完成记录。
- [x] 扩展阶段与类型列表、接口校验及助理提示；进度条保持单行七个节点。
- [x] 完整测试、类型检查和生产构建；本地预览验证。

约束：保持现有时间冲突、提醒、版本校验及老记录兼容性。沿用既有工作目录，局部变更，不新增依赖。

## 验证结果
- 新测试先失败（校验拒绝AI面、映射和进度节点缺失），实现后通过；完整测试 172/172、类型检查、生产构建通过。
- 本地 Workers 实际保存：AI面创建/编辑/清空结束时间/冲突回滚/并发保护/完成后状态同步/提醒均通过，测试账号及其数据已清理。
- 浏览器确认新增表单可选择 AI面、显示安排AI面时间，七节点进度条正确显示。
- 独立只读复核无阻塞发现。此次修改完成于本地，尚未发布线上。
